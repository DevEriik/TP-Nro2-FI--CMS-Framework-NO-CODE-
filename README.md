## 🎯 Objetivos del Trabajo Práctico

1. **Investigación y Selección Tecnológica:** Analizar y elegir un Sistema de Gestión de Contenidos (CMS) y un Framework adecuado para nuestro Proyecto Final ("ExpertoYa").
2. **Implementación de Template:** Elegir y aplicar un template CSS base acorde al dominio del proyecto, implementando modificaciones estructuradas.
3. **Gestión Ágil y Repositorio:** Documentar el proceso de trabajo mediante un tablero Kanban y gestionar el código colaborativamente utilizando Git (mediante _ramas_ por integrante).

---

## 📂 Estructura del Repositorio

- `/docs`: Contiene la documentación formal solicitada en las actividades teóricas.
  - 📄 [`justificacion_tecnica.md`](./docs/justificacion_tecnica.md): Documento con la fundamentación de las tecnologías seleccionadas (Express.js y Strapi) y el análisis de descarte de alternativas.
- `/src` _(o la carpeta donde guarden el código)_: Archivos del proyecto y el template CSS.

---

## 🛠️ Actividad 1: Selección de Herramientas

Luego de evaluar alternativas como NestJS, Django, WordPress y Contentful, el equipo ha decidido basar la arquitectura del proyecto final en el ecosistema **Node.js / TypeScript**:

- **Framework Backend:** Express.js
- **Headless CMS:** Strapi

> 🔗 _Para ver el análisis detallado y los motivos de descarte, referirse al archivo `/docs/justificacion_tecnica.md`._
